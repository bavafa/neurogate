# NeuroGate case-study site

Static page: plain HTML, CSS and JavaScript. No build step, no backend.

| Path | What it is |
|---|---|
| `index.html`, `css/`, `js/app.js` | The page. Charts and tables are drawn in the browser from `data/*.json`. |
| `js/golden.js` | JavaScript replay of the integer arithmetic in `model/golden.py` and `model/features.py`. |
| `data/` | Generated by `scripts/export_site_data.py`. Do not edit by hand. |
| `test/golden.test.mjs`, `test/all_packets.json` | Node test: JavaScript against the Python outputs on all 8,347 classified test packets. |
| `CHECKLIST.md` | Which number was checked against which file, and what could not be verified. |

## Regenerate the data

From the repository root, with the project's Python environment (NumPy and Scapy, see the main README):

```
python3 scripts/export_site_data.py
node site/test/golden.test.mjs
```

The export stops with a message if a number differs from `docs/results/metrics.json` or if a report format changed.
The test must print three `PASS` lines before the site is published.

## Preview locally

```
python3 -m http.server -d site 8000
```

Open http://localhost:8000. The page needs HTTP, because it loads JSON files (opening `index.html` as a file will not work).

## Deploy to Vercel

1. Import the GitHub repository in Vercel.
2. Set **Root Directory** to `site`. Framework preset: **Other**. Leave Build Command and Output Directory empty.
3. Deploy. Every file under `site/` is served as is. `site/test/all_packets.json` (about 0.4 MB) is only used by the node test; delete it from the deploy if you prefer, the page does not load it.

With the Vercel CLI: `cd site && vercel --prod`.
